AUTHENTICATION / LOCAL DEMO

Authentication demo

Create an account, log in, and validate a token.
Requests are handled by a WebAssembly component.

Requests

RUN IN ORDER   01 / 02 / 03
01POST /api/signup

Create an account

Register with an email address and password.

Use test credentials, not real ones.

02POST /api/login

Log in

Enter your account details to receive a signed token.

A successful login fills the token field.

03POST /api/validate

Validate a token

Check the token's signature and claims.

Tokens stay in this page, not browser storage.

Response

IDLE / READY
AWAITING REQUEST-- ms 
The response will appear here.
Start with 01 / Create an account.
For local testing only.

Accounts live in an in-memory Map. Restarting the server clears all accounts and replaces the signing key, invalidating old tokens. This demo is not intended for production use.

AUTHENTIKATEData is cleared when the server restarts.
